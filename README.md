# Project Overview
This was my final project for my Information Systems 471 - Big Data Analytics in Business course. The goal of the project was to predict the median value of a home based on 15 different housing characteristics given in the provided dataset.  
  
I used a supervised machine learning approach to train and evaluate the results of a linear regression model using a train-test split.
